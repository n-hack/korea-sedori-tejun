# 日本→韓国 無在庫の購買代行（せどり）の手順

> ⚠️ **未検証です。** 調べ物・規約の原文・小さな試算までで、本番の販売は1件もしていません。
> 売れる割合・1件の利益・アカウント審査の期間は、すべて他の人の実例か見込みです。使う前にご自身で確かめてください。

## 型（ひとことで）
日本の Amazon（Amazon ビジネス）で「売れてから」仕入れる → 韓国向けの転送業者（福岡の倉庫・船便）→ 韓国の買い手。
売り場はクーパン（主）・11番街（クーパンで出せない品）・スマートストア（手数料が最安）。
物差しは「手元に残る利益の額」（手数料・送料・為替・返品の引当を引き、消費税の還付を足す）。

## 1周の流れ（全部機械で回す設計）
1. 探す … 韓国の価格比較サイト（ダナワ）で「日本から代行販売されている品」を起点に型番を抜き、Keepa API で日本の値段と突き合わせる
2. 利益 … カテゴリ別の手数料・送金と為替・転送料・返品の引当を引き、還付（10/110）を足す。売値の下限もここで出す
3. 出品 … 韓国語の商品名（[해외]＋ブランドの韓国表記＋型番・容量）と説明（購買代行であること・日数・関税・返品送料・電圧）。クーパン公式 API（購買代行の項目あり）
4. 見張り … 仕入れ元の在庫が残り2点以下・値上がりで利益割れなら出品を止める（始めの数か月は残り5点で止める）
5. 受注 → 数分で Amazon ビジネスの発注 API で購入（届け先は転送業者の倉庫）→ 配送申請 → 追跡番号をモールへ返す
6. 問い合わせ … 定型4種（日数・関税・返品・在庫）は自動回答、それ以外は AI が読んで24時間以内に返す
7. 記録 … 仕入れ1件ごとに購入先・日付・品目・数量・金額・注文番号を残す（正品の証明に使う）

## 何を出すか（読んだ実例と試算から）
- 日本で売れている品だけ（日本で無名の物は韓国でも売れない）
- 韓国に製造メーカーが無い日本ブランドが強い … ゴルフ・卓球・釣り・アウトドア・日本メーカーの腕時計・ホビー
- 韓国に正規流通がある品は現地の方が安く負ける（例：電動工具の大手、世界ブランドのスポーツ時計）
- 売値は5万ウォン（約5,800円）以上だけ（それ以下は返品希望で自動返金になる、という語り手の話）
- 1つの JAN に複数の出品があるときはセット品を優先（単品は Amazon 本体と競合しやすい）
- 容量・サイズ・入り数・枝番は仕入れる品と完全に一致させる（違うと「別の品」で負ける）

## 出してはいけない品（出品前に機械で外す）
- 韓国の安全認証（KC）が無いと購買代行できない品目（携帯の充電器・LED電球・電気ベッドなど）
- 子ども用品・食品・医薬品・化粧品・洗剤・石けん・電池単体・スプレー・刃物・酒・たばこ
- ハイブランド・有名人の写真入り・日の丸／旭日・軍艦の図柄（知財の指摘3回で1か月停止の実例）
- 電気製品は「確かめる」扱い（100V→220V・変圧器を説明に明記・高単価だけ）

## どう守るか
- 仕入れ元の品切れによる取り消しが一番危ない（業者都合の取消率 1.0%以下という報道・始めは注文が少ないので1件が重い）
- 警告メールは放置しない（同じ警告が3〜4回で1か月停止の実例）
- 売れた実績のある商品ページは消さない（評価が振り出しに戻る）
- 同業者のページに相乗りせず、自分のカタログを作る（値崩れに巻き込まれない）
- 「作って放置」はしない（毎週、売れた／売れない品を入れ替える）
- いきなり大量に出さない … 開始週1日100件・週ごとに×1.5・同じブランドは1日10件まで（安全側の置き方）

## 規約・法律で確かめたこと（原文を読んだもの）
- クーパンの正品証明は「購入先・日付・品目が入った領収書かインボイス」（Amazon 本体の出品に限るとは書かれていない）。書類は1年有効、ブランド品は発行から6か月以内
- Amazon ビジネスの規約に、買った商品の転売を禁じる条文は無い。ロボット・収集ツールで価格を集めるのは禁止 → 価格は Keepa API、発注は Ordering API（日本対応）で正面から
- 楽天は自動購入を明文で禁止・Yahoo!ショッピングは無在庫を明文で禁止 → 自動で買えるのは Amazon ビジネスだけ
- 韓国の電子商取引法15条 … 代金を受けてから3営業日以内に「供給に必要な措置」。ただし供給時期を別に約定すればこの限りでない → 注文直後の発注と、出品時の出荷日数の明示で満たす
- 韓国の標準約款 … 日本で買う前なら取り消し可・不良は3か月・心変わりは7日
- 転送業者の公式 … 実重量のみ（容積重量なし）・0.5kg 900円から・保管30日無料・韓国に届いた品は日本へ戻せない・輸出許可書が出る（消費税還付に使える）
- 関税は150ドル超で買い手負担。判定は「支払った総額」＝購買代行では日本での仕入れ値（約2.2万円以下なら関税なし）

## 試算の結論（約300候補・本番の販売ではない）
- 韓国ですでに代行品が並んでいる品の利益は数百〜2,000円に収まることが多い
- 利益が大きいのは韓国にまだ無い品だが、売値の目安が無いので出して確かめるしかない
- → 出品は2本立て … ①相場のある品を最安より少し下で出して評価を積む ②韓国に無い品を仕入れ×2前後で出し、売れた品を増やす
- 腕時計（日本メーカー）とゴルフが利益額の上位。時計は小さく軽いが、電池の船積みは転送業者に要確認 → 機械式から出す

## 見込み（正直に・自分では未実測）
- 登録 数週間〜3か月 ＋ 売れ始めるまで2〜3か月 ＝ 軌道まで約3〜6か月
- 売れる割合の実例は1万品で月0.5〜0.9%。1件2,000円なら1店1万品で月10〜18万円
- 韓国は11〜2月が強く、7〜8月と10月が弱い → 出品を増やすのは秋

## 始める前に要るもの
- 開業届（または法人）・インボイス番号・パスポート・事業所の住所の書類
- Payoneer（クーパンの入金先）／11番街・スマートストアは事業名義の海外送金を受けられる口座
- クーパン・11番街の販売者登録（11番街のセラー API は呼び出し元の IP の事前登録が要る＝固定 IP）
- 転送業者の会員登録・Amazon ビジネス＋Business プライム（少額も送料無料）・発注 API の開発者申請
- 画像の方針 … Amazon の商品画像の転載は権利が未確定。卸の「画像転載可」の品・メーカーの販売店向け素材が安全側

## まだ確かめていないこと
- クーパン・Amazon ビジネス・転送業者の本物の鍵での1件（全部、登録待ち）
- クーパンの販売者点数の公式の線（ログインの内側）
- 自分での売れる割合・返品率・取消率（最初の3か月で数える数字）
